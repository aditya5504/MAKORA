MAKORA Women's Store — quick setup

1. Open index.html in a browser to preview the website.
2. Edit the WhatsApp number in the script near the bottom:
   const WHATSAPP_NUMBER = "91XXXXXXXXXX";
   Use country code + number, digits only (no + or spaces).
3. Replace sample product names, prices, sizes and image URLs with your real products.
4. Replace Instagram, email and WhatsApp links in the footer.
5. Publish free using GitHub Pages:
   - Create/sign in to a GitHub account.
   - Create a new public repository named makora-store.
   - Upload index.html.
   - Open Settings > Pages.
   - Under Build and deployment, choose Deploy from a branch.
   - Select main and /(root), then Save.
   - GitHub will provide your free website URL after deployment.

Notes:
- This is a free catalogue-style storefront with WhatsApp ordering, not an automated checkout.
- Product prices and photos are illustrative placeholders. Confirm stock, prices, shipping, returns and policies before launch.
- External photos require internet access and should be replaced with photos you own or have permission to use.
